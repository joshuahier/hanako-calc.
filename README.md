# 👻 Hanako Calculator (`hanako-calc`)

A custom, web-based calculator themed around *Toilet-bound Hanako-kun*, featuring custom Hakujoudai spirit accents, dynamic UI layouts, and interactive arithmetic operations.

---

## ✨ Features

- **Thematic Design:** Custom dark crimson aesthetic with Hakujoudai spirit elements and stylized keypad graphics.
- **Full Standard Arithmetic:** Performs addition (`+`), subtraction (`-`), multiplication (`x`), and division (`:`).
- **Responsive Web Interface:** Built purely with semantic HTML, CSS styling, and vanilla JavaScript logic.
- **Clear & Reset Functions:** Instant display clearing and recalculation workflows.

---

## 🛠️ Tech Stack

- **HTML5** – UI structure and layout grid
- **CSS3** – Custom theme palette, flexbox/grid layout, and visual assets
- **JavaScript (ES6+)** – DOM manipulation and calculation logic
